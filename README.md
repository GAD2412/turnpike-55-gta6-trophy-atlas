Turnpike 55 is an offline guide and tracker for all 55 PS5 trophies of Grand Theft Auto VI. It shows the official names, descriptions and grades, gives each trophy a guide that cites dated sources, and lays out a six-leg platinum route with the one potentially missable trophy flagged. It also has a spoiler shield, filters and search, keyboard control, and progress saved in the browser with export, import and print.

## Run it

```sh
node serve.ts
```
